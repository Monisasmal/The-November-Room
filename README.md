
# 🏋️ The November Room  

A modern and responsive **fitness and training center landing page** built using **HTML and CSS only**.  
The project showcases a bold and powerful design that highlights gym features, trainers, and a contact form.  

👉 **Live Demo:** [The November Room](https://monisasmal.github.io/The-November-Room/)  

---

## 📸 Project Preview  

### 🔹 Hero Section  
- Strong visual banner with motivational text  
- Call-to-action button to **Download Brochure**  

### 🔹 About Section  
- Information about gym safety and facilities  
- Features like latest equipment, quality flooring, and professional trainers  

### 🔹 Trainers Section  
- Dedicated cards to introduce fitness trainers  
- Clean, responsive layout for better presentation  

### 🔹 Contact Section  
- Functional contact form design (frontend)  
- Collects **Full Name, Email, and Message**  
- Engaging **“Want to work with us?”** call-to-action  

---

## ✨ Features  

- 📱 Fully responsive design  
- 🎨 Stylish UI with gym-themed layout  
- ⚡ Smooth user experience with only **HTML & CSS**  
- 📑 Clear structure divided into **Hero, About, Trainers, and Contact** sections  
- 🌐 Links for **social media integration**  

---

## 🛠️ Tech Stack  

- **HTML5** – Page structure  
- **CSS3** – Styling and layout (responsive design)
